# 📈 Stock Portfolio Tracker

A simple **Stock Portfolio Tracker built using Python**. The user can enter stock names and quantities, and the program calculates the investment for each stock and the total investment.

## 📌 Project Description

This Python-based Stock Portfolio Tracker uses a predefined dictionary containing stock names and their prices. The user can enter multiple stocks and their quantities.

The program calculates the investment amount for each stock and adds all investments to calculate the total investment.

The game/program ends when the user enters `done`.

## 🛠️ Technologies Used

- **Python**
- Dictionary
- `while` loop
- Conditional statements
- User input

## ✨ Features

- Predefined stock prices
- Stock name validation
- Accepts stock quantity
- Calculates individual investment
- Calculates total investment
- Supports multiple stocks
- Handles unavailable stocks
- Simple command-line interface
