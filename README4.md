# 🤖 Basic Chatbot

A simple **Rule-Based Chatbot built using Python**. The chatbot responds to predefined user inputs such as greetings, AI-related questions, help requests, and current date and time.

## 📌 Project Description

This Python-based chatbot uses simple `if-elif-else` conditions to understand user inputs and provide predefined responses.

The chatbot can respond to greetings, explain what AI is, tell the user how it is doing, provide help, and display the current date and time.

The chatbot ends when the user enters `bye`.

## 🛠️ Technologies Used

- **Python**
- `datetime` module
- Conditional statements
- Functions
- User input

## ✨ Features

- Responds to greetings
- Provides a basic explanation of AI
- Responds to "How are you?"
- Provides help instructions
- Displays current date and time
- Handles invalid responses
- Allows the user to exit using `bye`
- Simple command-line interface
